# المزارع 🌴🐪

لعبة أندرويد عربية **2.5D (إيزومتريك)** بروح **Graveyard Keeper** وتجارة زي **Hay Day**. ورثت مزرعة عمك سالم وخان قديم على طريق البخور:
اجمع، ازرع، اصنع، رمّم الخان، استقبل القوافل، وانزل السرداب بالليل مع زعبول، جني الفانوس اللي لسانه طويل.

## وش فيها؟
- **جمع وصناعة:** نخل، حجر، طين، ماء، أعشاب. وعندك منجرة، وفرن فخّار، وموقد قهوة، ورحى، ونول.
- **زراعة:** طماطم، قمح، بطيخ، هيل. تزرع وتسقي كل يوم وتحصد.
- **ترميم الخان:** 16 موقع بناء، وكل واحد يرفع سمعة الخان لين توصل 5 نجوم.
- **قوافل وضيوف:** كل صباح توصل قافلة، والضيوف يطلبون قهوة وتمر وخبز. وأحياناً تجي قافلة ذهبية تدفع ثلاث أضعاف.
- **أيام الأسبوع:** كل تاجر يجي بأيام معيّنة، والجمعة يوم السوق.
- **شجرة المعرفة:** 20 تقنية تفتحها بثلاث أنواع نقاط (حِرفة، طبيعة، أسرار).
- **السرداب:** 3 طوابق تنولد عشوائياً، فيها عقارب وغيلان وخفافيش و3 زعماء.
- **قصة:** 16 مهمة باللهجة الخليجية.
- **ليل ونهار:** إضاءة فوانيس، وحباحب، وموسيقى عود على مقام الحجاز.
- **حركات لكل فعل:** تنحني وتزرع، تميّل الجرة وتكب الماء، تسحب الدلو من البير، تحلب، وتطعم.
- **تربية النياق:** مراح وحوض ماء تعبّيه بنفسك، وسلالات (مجاهيم، وضح، شعل، صفر، حمر، شقح). تسقي وتطعم وتحلب وتلقّح، والحمل 3 أيام.
  **كل حوار فيه فرصة 2% يطلع نادر** (الذهبية، الوضحاء الملكية، الشعلاء النارية) وقيمته عشرات أو مئات الألوف.
- **سوق الحلال:** تجار افتراضيين لكل واحد طبعه (كريم، مفاصل، مستعجل، عنيد، نصّاب). تبيع وتشتري وتساوم بمحادثة،
  وتقايض ناقة بناقة مع فرق دراهم. والنادرة تجيب مزايدة بين أكثر من مشتري. ومؤشر السوق يتغير كل يوم.
- **العمّال:** توظّف حطّاب ومزارع وبنّاء وراعي، ويشتغلون لحالهم. رواتبهم بالساعة باللعبة، وإذا تأخرت 3 ساعات
  يضربون ✊ وما يرجعون إلا إذا دفعت الراتب **+ غرامة**. وفيه دفع تلقائي.
- **التجارة زي Hay Day:** بسطة على الطريق تعرض فيها زرعك وغنمك بسعرك، والمارّة يشترون (كل ما رخّصت انباع أسرع).
  وفيه لوحة قافلة الطلبات، وجريدة السوق، وحظيرة غنم (نجدي، نعيمي، حرّي) تجز صوفها وتبيعها.
- **مزاين الإبل:** كل جمعة تشارك بأجمل ناقة وتفوز بجوائز.

## نظام المكافآت
مكافأة يومية على تقويم 7 أيام مع سلسلة دخول، و3 مهام يومية وصندوق إذا خلصتها، وعجلة حظ، و36 درجة إنجاز،
وصناديق كنز بثلاث درجات، وأرباح وأنت غايب (لين 8 ساعات)، وألبوم تحف يعطيك ميزات دائمة، وترقية مستويات،
وإشعار يذكّرك بالمكافأة اليومية.

## الإعلانات (AdMob بمكافأة)
أماكن الإعلانات: مضاعفة المكافأة اليومية، مضاعفة أرباح الغياب، مضاعفة الصندوق، لفة زيادة بالعجلة، تعبئة الطاقة،
والرجوع للحياة بالسرداب. الحد 12 إعلان باليوم.

المعرّفات الحالية **تجريبية**. عشان تكسب منها فلوس:
1. سوّ حساب في [AdMob](https://admob.google.com) وأضف التطبيق.
2. سوّ وحدة إعلانية من نوع **Rewarded**.
3. افتح `android/app/build.gradle` وبدّل `admobAppId` و`admob_rewarded_id` بمعرّفاتك.

## كيف أنزّلها على جوالي؟
كل مرة ينرفع كود جديد، GitHub Actions يبني ملف `almuzare.apk` تلقائياً:
- من صفحة **Releases** بالمستودع، نزّل `almuzare.apk` من آخر نسخة.
- أو من تبويب **Actions**، افتح آخر تشغيل ونزّل `almuzare-apk`.

بعدها ثبّت الملف على الجوال، ولازم تسمح بالتثبيت من مصادر غير معروفة.

## للمطوّرين
```bash
npm test            # اختبارات منطق اللعبة
npm run serve       # تشغيل اللعبة بالمتصفح على http://localhost:8080
npm i && npm run smoke   # اختبار آلي بمتصفح Chromium مع لقطات شاشة
```
- `web/`: اللعبة نفسها (HTML5 Canvas + JavaScript بدون أدوات بناء).
- `android/`: غلاف أندرويد (WebView + AdMob + إشعارات).
- `scripts/make-icons.mjs`: يولّد أيقونة التطبيق.

للنشر على Google Play تحتاج نسخة release موقّعة بمفتاحك، وسياسة خصوصية، ونافذة موافقة UMP لمستخدمي أوروبا.
