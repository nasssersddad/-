# 🙃 أوبي المقلوب — لعبة روبلوكس

أوبي فيه **20 مرحلة** موزّعة على **5 عوالم**، وكل عالم يغيّر طريقة اللعب:

| العالم | المراحل | وش يصير؟ |
|---|---|---|
| 🟢 البداية | 1–4 | أوبي عادي تسخّن فيه: نطّات، حمم، منصة تتحرك، عصا تدور، وسلّم |
| 🌙 القمر | 5–8 | **الجاذبية خفيفة** والدنيا ليل، تنطّ بعيد والفراغات أوسع |
| 🔄 المعكوس | 9–12 | **التحكم معكوس**: قدّام يوديك ورا، ويمين يوديك يسار |
| 🙃 الدنيا مقلوبة | 13–16 | **الكاميرا مقلوبة** راس على عقب |
| ⏪ الوقت المعكوس | 17–20 | الألوان قديمة، و**المنصات تختفي وترجع** بالتناوب، وفيها منصات قفز خارق |

وفيه بعد:
- **نقاط حفظ** بكل مرحلة، تتلوّن بالأخضر لما توصلها، ولو متّ ترجع لآخر نقطة.
- **مؤقت** يحسب وقت الجولة، ويحفظ **أفضل وقت** لك (لو بدأت من المرحلة 1).
- **لوحة اللاعبين** فيها المرحلة وعدد مرات الفوز.
- **لافتة** تطلع لك لما تدخل عالم جديد، وصوت مع كل نقطة حفظ.
- **شاشة فوز** في النهاية، وزر «العب من جديد».
- **حفظ التقدّم:** لو طلعت ورجعت تكمّل من نفس المرحلة.

## 🪢 وضع الحبل التعاوني: «درب الحبل»

في اللوبي فيه دائرتين مكتوب عليهم **🪢 1** و **🪢 2**. كل لاعب يوقف على دائرة، وبعد 3 ثواني تنربطون بحبل وتنقلون لمسار خاص فيه **8 مراحل**:

- **الحبل يسحبكم لبعض:** طوله 16 ستد، ولو واحد ابتعد أكثر يتسحب الثاني وراه.
- **لو واحد طاح، الثنين يرجعون** لآخر نقطة حفظ مشتركة.
- **🪢 اسحب (زر E، أو الزر اللي يطلع بالجوال):** يقصّر الحبل. لو خويك معلّق تحت الحافة، اسحبه لفوق!
- **🔘 جسور بأزرار:** الفراغ أبعد من النطّة. واحد يوقف على الزر عشان يطلع الجسر والثاني يعبر، وبعدين اللي عبر يوقف على الزر الثاني عشان يعبر خويه.
- **طريقين ضيقين وبينهم حمم:** كل واحد ياخذ طريق.
- وفيه بعد: منصة تتحرك تشيلكم الثنين، سلّم عريض، حجار فوق الحمم، عصا تدور، ومنصات تختفي.
- **مؤقت مشترك**، وعمود **🪢** في لوحة اللاعبين يحسب كم مرة خلّصتوا.
- زر **✂️ فك الحبل** يرجّعكم الثنين للأوبي العادي.

> **تجربه في Studio لحالك؟** من تبويب **Test** اختر **Clients and Servers**، وحط عدد اللاعبين **2**، واضغط **Start**.
> بتطلع لك نافذتين، وكل نافذة توقف بلاعبها على دائرة.

## كيف تشغّلها؟ (أسهل طريقة)

1. نزّل وثبّت [Roblox Studio](https://create.roblox.com/) لو ما عندك.
2. نزّل الملف [`FlippedObby.rbxlx`](FlippedObby.rbxlx) من هالمجلد.
3. افتح Roblox Studio، واختر **File ← Open from File** وافتح الملف.
4. اضغط **Play** ▶️ وجرّب!

> الخريطة كلها تنبني بالكود أول ما تشتغل اللعبة، فبتشوف الدنيا فاضية في Studio قبل ما تضغط Play، وهذا طبيعي.

## كيف تنشرها على روبلوكس؟

1. في Studio اختر **File ← Publish to Roblox** وسمّها.
2. عشان يشتغل الحفظ: **Home ← Game Settings ← Security** وفعّل **Enable Studio Access to API Services**.
3. من [Creator Dashboard](https://create.roblox.com/dashboard/creations) خلّ اللعبة **Public** عشان يدخلها الناس.

## كيف تعدّل عليها؟

كل شي تقريباً في ملف واحد: [`src/shared/Config.luau`](src/shared/Config.luau).

- **تزيد مرحلة؟** زِد سطر في `Config.Stages`، مثلاً:
  ```lua
  { world = 3, segments = { { type = "jumps", count = 6, gap = 4 }, { type = "spinner", radius = 10, speed = 2 } } },
  ```
- **أنواع العقبات:** `jumps` (نطّات)، `lava` (حمم وحجار)، `beam` (خشبة رفيعة)، `zigzag` (يمين ويسار)،
  `mover` (منصة تتحرك)، `spinner` (عصا تدور)، `truss` (سلّم)، `vanish` (منصات تختفي)، `pad` (قفز خارق).
- **تصعّبها؟** كبّر `gap` (المسافة بين المنصات)، أو زِد `speed` للعصي، أو صغّر `period` للمنصات اللي تختفي.
- **عالم جديد؟** زِد عالم في `Config.Worlds` بحركة من الحركات الموجودة (`none`, `lowGravity`, `invert`, `flipCamera`, `rewind`).
- **درب الحبل؟** مراحله في `Config.Coop.stages`، وفيه عقبتين خاصة فيه: `bridge` (جسر بأزرار) و `lanes` (طريقين).
  وتقدر تغيّر طول الحبل وقوة السحب من `Config.Coop`.

### الملفات

| الملف | وش فيه |
|---|---|
| `src/shared/Config.luau` | العوالم والمراحل والأرقام |
| `src/shared/Format.luau` | تنسيق الوقت |
| `src/server/Main.server.luau` | السيرفر: نقاط الحفظ، الفوز، البداية من جديد، والحفظ |
| `src/server/CourseBuilder.luau` | يبني اللوبي والمراحل والنهاية بالكود |
| `src/server/Coop.luau` | 🪢 الوضع التعاوني: الربط، الحبل، النقاط المشتركة، الجسور، والسحب |
| `src/server/Data.luau` | حفظ وتحميل التقدّم (DataStore) |
| `src/client/Mechanics.client.luau` | يحرّك المنصات، الموت من الحمم، القفز الخارق، حركات العوالم، وسحب الحبل |
| `src/client/Hud.client.luau` | الواجهة: المرحلة، المؤقت، اللافتات، شاشة الفوز، وواجهة درب الحبل |
| `tests/run_course_check.py` | يفحص إن كل المراحل تنقطع وإن جسور درب الحبل تحتاج زر (بدون Studio) |

### لو تبي تعدّل بالكود وتبني الملف من جديد

المشروع مسوّى بـ [Rojo](https://rojo.space/). بعد ما تعدّل:

```bash
cd roblox
rojo build default.project.json -o FlippedObby.rbxlx
```

أو شغّل `rojo serve` واربطه بإضافة Rojo داخل Studio عشان يتحدّث على طول وأنت تعدّل.

وعشان تتأكد إن المراحل تنقطع بعد ما تعدّلها (تحتاج أداة [luau](https://github.com/luau-lang/luau/releases)):

```bash
python3 roblox/tests/run_course_check.py
```
